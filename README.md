# ⚾ Base-On AI 광고 프로젝트

> **야구를 켜다. 승리를 읽다. 베이스온.**

AI 이미지·비디오·오디오 생성 도구를 활용하여 야구팬의 **패배 후 허탈감 → 내일 경기에 대한 기대감**으로 이어지는 감정 변화를 10초 광고 영상으로 제작한 프로젝트입니다.

---

## 📌 1. 프로젝트 개요

### 프로젝트명

**Base-On AI Advertisement**

### 프로젝트 목적

경기가 끝난 후에도 다음 경기와 선발 정보를 찾아보는 야구팬의 행동에 주목하여,
베이스온이 제공하는 **내일 선발 및 전력 분석 데이터**를 통해 패배의 감정을 새로운 기대감으로 전환하는 광고를 제작했습니다.

### 핵심 메시지

> **“야구를 켜다. 승리를 읽다. 베이스온.”**

# 🏷️ 2. 브랜드 아이덴티티

| 항목                | 정의                                                      |
| ----------------- | ------------------------------------------------------- |
| **브랜드명**          | 베이스온 (Base-On)                                          |
| **Target**        | 2040 야구팬. 패배 직후에도 다음 경기의 선발·전력 정보를 확인하며 야구를 계속 이어가는 사람들 |
| **Tone & Manner** | 미니멀리즘 / 신뢰감 / 감성적                                       |
| **USP**           | 분노를 희망으로 바꾸는 가장 빠른 데이터. 특히 내일 선발과 전력 분석 정보를 빠르게 제공      |
| **광고 목적**         | 브랜드 인지도 향상 및 서비스 가치 전달                                  |
| **핵심 메시지**        | **“야구를 켜다. 승리를 읽다. 베이스온.”**                             |

### 브랜드 차별점

베이스온은 단순히 경기 결과를 확인하는 서비스가 아니라,
**경기가 끝난 뒤에도 다음 경기를 준비할 수 있도록 선발과 전력 데이터를 제공하는 서비스**를 지향합니다.

따라서 이번 광고에서는

**패배 → 허탈함 → 궁금증 → 데이터 확인 → 기대감**

이라는 감정 변화를 통해 베이스온의 가치를 표현했습니다.

# 🎯 3. 캠페인 목표

### 광고 목적

**브랜드 인지도 향상 + 서비스 가치 전달**

경기에서 패배한 순간에도 야구팬이 다음 경기의 정보를 찾는 행동을 보여주고,
베이스온의 **내일 선발 및 전력 분석 기능**을 통해 다시 기대감을 갖게 하는 것을 목표로 합니다.

### 핵심 타깃

* 20~40대 야구팬
* 야구 경기를 꾸준히 시청하는 사용자
* 경기 결과뿐만 아니라 다음 경기의 선발 정보를 확인하는 사용자
* 팀이 패배해도 다음 경기를 계속 기다리는 팬

# 🎬 4. 광고 서사

이번 광고는 단순한 컷 나열이 아닌 **문제 제시 → 전환 → 해결/제안 → 브랜드 각인** 구조로 제작했습니다.

### 전체 스토리

**문제 제시**

경기에서 패배한 야구팬이 허탈함을 느낀다.

↓

**감정 전환**

"다시는 안 본다"라고 생각하지만 휴대폰을 집어 든다.

↓

**해결 / 제안**

베이스온에서 내일 선발과 전력 정보를 확인하며 다시 기대감을 갖는다.

↓

**브랜드 각인**

베이스온 로고와 슬로건을 통해 브랜드를 기억시킨다.

### 씬 구성

| 씬      |    시간 | 핵심 장면           | 역할          |
| ------ | ----: | --------------- | ----------- |
| **01** |  0~4초 | 경기 종료 후 거실의 야구팬 | 문제 제시       |
| **02** |  4~6초 | 휴대폰을 확인하는 순간    | 감정 전환       |
| **03** |  6~7초 | 내일 선발·전력 정보 확인  | 해결 / 서비스 가치 |
| **04** | 7~10초 | 베이스온 로고 및 슬로건   | 브랜드 각인      |

> **마지막 3초(7~10초)는 브랜드 인지를 위한 구간으로 구성하여 베이스온의 브랜드명과 슬로건을 노출합니다.**

# 🎞️ 5. 씬별 스토리보드

## Scene 01 — 패배의 밤

**길이:** 0~4초

### 목표 메시지

> 패배 후 느끼는 야구팬의 허탈한 감정을 보여준다.

### 화면 구성

어두운 거실에서 경기 종료 후 TV를 바라보는 야구팬을 표현합니다.
전체적으로 어두운 분위기와 감정적인 표정을 사용하여 패배 직후의 허탈함을 전달합니다.

### 내레이션 / 카피

> **“또 졌네 다신 안 본다”**

### 사용 도구

* **Gemini** — 야구팬의 감정과 거실 장면을 표현하기 위한 키비주얼 생성
* **Google Flow** — 생성된 이미지를 짧은 영상으로 변환
* **ElevenLabs** — 감정에 맞는 내레이션 생성
* **CapCut** — 영상 및 오디오 편집

### 입력 프롬프트

```text
When turning off the TV, change the narration to "I lost again, I'm never watching this again" along with matching lip movements. And when picking up the phone, change the motion to tapping the phone, and add the narration "Who is coming out tomorrow?" with matching lip movements.
```

### 출력 결과

야구팬의 패배 직후 감정과 밤의 분위기를 묵직하고 신뢰감 있게 표현한 키비주얼을 확보했습니다.

`BaseOn_S01_Intro.mp4`

# 🤖 6. 멀티모달 생성 도구

| **Gemini**      | 이미지 생성 AI    | 야구팬의 감정, 거실, 스마트폰, 야구장 등의 장면을 빠르게 시각화하고 광고의 키비주얼을 확보하기 위해 사용 |
| **Google Flow** | 비디오 생성·변환 AI | 생성된 이미지를 움직이는 영상으로 변환하고 인물의 움직임과 카메라 모션을 추가하기 위해 사용          |

| **CapCut**      | 영상·오디오 편집    | 생성된 영상 컷을 선별·연결하고 내레이션, 배경음악, 로고, 엔딩 카피를 하나의 광고로 통합하기 위해 사용  |

# ✏️ 7. 프롬프트 개선 과정

AI를 이용해 영상을 생성하는 과정에서 한 번에 완성된 영상을 만들기보다, **생성 결과를 확인한 후 필요한 부분을 선별하여 편집하는 방식**으로 제작 방법을 개선했습니다.

| 구분             | 내용                                                                                                                                                                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **수정 전 프롬프트**  | `When turning off the TV, change the narration to "I lost again, I'm never watching this again" along with matching lip movements. And when picking up the phone, change the motion to tapping the phone, and add the narration "Who is coming out tomorrow?" with matching lip movements.` |
| **발생한 문제**     | 여러 동작과 대사를 한 번에 생성하면서 영상 일부가 버벅이고 장면 전환이 부자연스러웠으며, 불필요한 자막이 포함되는 문제가 발생                                                                                                                                                                                                                     |
| **수정 후 제작 방식** | 여러 버전의 생성 영상에서 필요한 구간을 선별하고, 불필요한 구간과 자막이 포함된 부분을 삭제한 뒤 원하는 장면만 이어 붙임                                                                                                                                                                                                                       |
| **수정 이유**      | 하나의 긴 영상을 AI로 완성하기보다 필요한 장면을 개별적으로 생성·선별하고 편집하는 방식이 10초 광고의 자연스러운 흐름과 완성도를 높이는 데 적합하다고 판단                                                                                                                                                                                                   |
| **결과 변화**      | 버벅임과 불필요한 장면이 줄어들었고, 필요한 컷만 연결하여 영상의 흐름이 자연스러워짐                                                                                                                                                                                                                                             |

### 개선을 통해 얻은 점

AI 생성 결과를 그대로 사용하는 것보다 **생성 → 결과 확인 → 문제점 파악 → 필요한 부분 선별 → 편집**의 과정을 거치는 것이 최종 광고의 완성도를 높이는 데 효과적이라는 것을 확인했습니다.
